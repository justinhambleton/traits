# Live A/B Evaluation

This directory stores live A/B evaluation artifacts where responses are generated by a provider model and then scored by Tier 1/2/3 evaluators.

## Script

Use:

```bash
node experiment/scripts/run-live-ab-eval.mjs --profile profiles/resolve.yaml --tier 3
```

Key options:

- `--profile`: starter profile path (`profiles/haven.yaml`, `profiles/resolve.yaml`, etc.)
- `--ids`: comma-separated scenario ids (defaults depend on profile)
- `--tier`: highest tier to run (`1|2|3`)
- `--generation-provider`: `auto|openai|anthropic`
- `--generation-model`: generation model id
- `--judge-provider`: provider for Tier 3 scoring (`auto|openai|anthropic`)
- `--judge-model`: judge model id for Tier 3
- `--embedding-model`: OpenAI embedding model for Tier 2
- `--generic-system`: generic-arm system prompt override
- `--out`: output JSON path
- `--dry-run`: prints plan and availability without making provider calls

Provider credentials:

- `TRAITS_OPENAI_API_KEY` for OpenAI generation and Tier 2 embeddings
- `TRAITS_ANTHROPIC_API_KEY` for Anthropic generation and/or Tier 3 judging

## Output

Each run writes a JSON report under `experiment/evaluation/runs/` including:

- generated responses for compiled and generic arms
- per-tier report payloads for each arm
- per-tier average deltas and per-scenario deltas
- run metadata (providers, requested tier, resolved tiers, scenario ids)
